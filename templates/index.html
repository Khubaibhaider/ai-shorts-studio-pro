Option 2: NVIDIA GPU Users — LM Studio + Dolphin Model (Pro Viral AI)

Want local GPU-accelerated LLM reasoning for gaming, comedy, and unfiltered viral hooks? Follow these 4 steps:

  1. Download and install LM Studio from lmstudio.ai.
  2. In LM Studio's Discover / Search tab, search for and download this exact model & quantization:
    Dolphin3.0 Llama3.1 8B Q4_K_S
    Make sure to pick the Q4_K_S quantization tag so it runs smoothly on your NVIDIA GPU VRAM.
  3. Open the Local Server (<->) tab on the left sidebar of LM Studio, load Dolphin3.0 Llama3.1 8B (Q4_K_S) at the top (enable GPU Offload), and click Start Server (port 1234).
  4. Back in AI Shorts Studio Pro, set Processing Hardware to NVIDIA GPU (CUDA) and AI Brain Engine to LM Studio (GPU Local Server :1234).
